# FoxCanvas

FoxCanvas — приложение для работы с идеями на досках. На доску можно добавлять заметки, текст и фигуры, соединять их стрелками и перемещать. Доски сохраняются автоматически. Ещё есть импорт и экспорт в JSON и помощник для генерации идей.

## Что нужно

- Node.js 20 или новее
- npm 10 или новее

## Запуск

1. Установите зависимости:

   ```bash
   npm install
   ```

2. Создайте файл настроек:

   ```bash
   cp .env.example apps/api/.env
   ```

3. Сгенерируйте секрет для входа:

   ```bash
   openssl rand -base64 48
   ```

   Скопируйте результат в `JWT_SECRET` в файле `apps/api/.env`.

4. Подготовьте базу данных и запустите приложение:

   ```bash
   npm run prisma:generate
   npm run db:push
   npm run dev
   ```

Откройте [localhost:5173](http://localhost:5173) и создайте аккаунт. API запускается на порту 3001. Для остановки нажмите `Ctrl+C` в терминале.

## Настройка нейросети

Нейросеть необязательна: досками можно пользоваться и без неё. Чтобы включить генерацию, добавьте ключ OpenRouter в `apps/api/.env`:

```dotenv
AI_BASE_URL="https://openrouter.ai/api/v1"
AI_API_KEY="ваш-ключ"
AI_MODEL="openai/gpt-4o-mini"
```

После изменения файла перезапустите API. Модель можно заменить на другую доступную в OpenRouter. Если появляется ошибка 401, проверьте ключ и доступ к модели; если 402 — баланс аккаунта. Ключ хранится на сервере и не отправляется в браузер.

При добавлении результата на доску создаётся заголовок и заметки, соединённые с ним стрелками. Проверяйте результат: нейросеть может ошибаться.

## Сохранение досок

Изменения сохраняются автоматически. Если связь с сервером пропала, приложение сохраняет локальный черновик в браузере и попытается восстановить его при следующем открытии доски, если серверная версия не изменилась. Локальный черновик не заменяет резервную копию: его можно потерять при очистке данных браузера.

## Команды

```bash
npm run dev           # запустить приложение для разработки
npm test              # запустить тесты
npm run typecheck     # проверить типы
npm run build         # собрать приложение
npm run format        # отформатировать код
npm run format:check  # проверить форматирование
```

Для запуска собранного API используйте `npm run start -w @foxcanvas/api`. Файлы интерфейса находятся в `apps/web/dist`; запросы к `/api` нужно направить на API. Для рабочего развёртывания нужен HTTPS. Настройку `TRUST_PROXY` меняйте только при работе через доверенный обратный прокси.

## Структура проекта

- `apps/web` — интерфейс на React и редактор досок.
- `apps/api` — сервер, авторизация, база SQLite и запросы к нейросети.
- `packages/canvas-schema` — общий формат и проверка данных доски.
